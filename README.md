# Clarity Invest Pro Dashboard

Beginner-friendly investing dashboard built using Streamlit.

## Features
- Stock Analysis
- Risk Analysis
- Company Comparison
- SIP Calculator
- Portfolio Allocation
- Beginner Investment Insights
- Latest Stock News

## Tech Stack
- Python
- Streamlit
- Plotly
- yFinance
- Pandas

## Run Locally

pip install -r requirements.txt

streamlit run app.py
